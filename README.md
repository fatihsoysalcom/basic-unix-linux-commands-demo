# Basic UNIX Linux Commands Demo

This Bash script demonstrates fundamental UNIX/Linux commands and concepts. It creates a temporary directory structure, manipulates files and their content, lists directory contents, uses command piping, and performs basic conditional checks. The script cleans up all created files and directories upon completion.

## Language

`bash`

## How to Run

1. Save the code as `unix_fundamentals.sh`.
2. Open a terminal and navigate to the directory where you saved the file.
3. Make the script executable: `chmod +x unix_fundamentals.sh`.
4. Run the script: `./unix_fundamentals.sh`.
